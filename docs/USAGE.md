# 使用说明

## 1. 首次使用

打开 App 后，先到「设置」确认三项：

1. **校区**：未来城 / 南望山，决定默认作息
2. **每天小节数**：未来城 12，南望山 10
3. **开学第一周周一**：例如 `2026-09-28`。按教务系统显示的第一周周一填写

设置好后，表头会显示 `周一 10/26` 这样的日期；系统当天所在周、当天那一列才会高亮。

---

## 2. 从教务导入课表

1. 底部「导入」→「导入课表」→「从教务网页导入」
2. 在页面里登录学校统一身份认证
3. 进入「信息查询 → 学生个人课表」
4. 选好学年/学期，点「查询」，等表格出现
5. 点右上角「提取课表」
6. 预览确认后选「覆盖保存」或「追加」

说明：

- 应用**不会**保存账号密码；登录完全在学校页面里完成
- 如果提示「当前页面不像课表页」，说明还没进到课表查询结果页
- 校外访问不了教务时，先连学校 WebVPN 再操作

---

## 3. 从教务导入考试

1. 「导入」→「导入考试」→「从教务网页导入」
2. 进入「信息查询 → 考试信息查询」
3. 点「查询」
4. 点「提取考试」，预览后保存

考试会按日期换算到对应周次，按开考时间落到课表节次，显示为红色「考试」块。

也可以：

- 「粘贴文本导入」：每行一场考试
- 「手动添加考试」
- 「查看考试列表」：编辑/删除已有考试

---

## 4. PDF / 文本 / 手动导入

- **PDF**：导入 → 导入课表 → 从 PDF 导入 → 选文件。解析失败会自动进入文本编辑页
- **文本**：粘贴含「周几 / 第几节 / 周次 / 地点」的内容
- **手动**：直接点课表空白格，在对应位置新建

---

## 5. 学期与历史课表

点底部「课表」打开学期面板：

- 顶部是当前学期
- 下方是历史课表
- 点历史学期即可切换，旧课表原样保留
- 历史课表左侧 `≡` 可上下拖动排序，松手即保存
- `+ 新建学期`：填名称与开学日
- 每张卡片右侧 `⋯`：重命名、修改开学日、删除

导入的课程/考试永远写入**当前选中的学期**。

---

## 6. 新建实验

1. 点课表里的空白格
2. 填课程名、教室、老师
3. 周次默认当前周单周，可在保存前修改
4. 打开「实验（课程的下属）」，可填所属课程
5. 保存后显示为琥珀色「实验」块
6. 长按块体可拖动换位置，拖下沿可改结束节

实验只能手动创建，不会从教务导入。

---

## 7. 修改课程

- 点击课程块：查看/编辑课程名、教室、老师、周次、星期、起止节
- 新增课程时「详细信息」默认收起，点标题可展开课程号、班级、学分、校区、考核、学时、备注
- 新增课程周次默认当前周单周；编辑已有课程时详细信息默认展开
- 长按块体：拖动换天/换节
- 拖块体下沿：改结束节
- 如果目标位置已有周次重叠的课，会提示冲突并回滚

---

## 8. 主题与背景

「主题」页：

- **深色主题**：全局切换
- **选择图片**：优先打开图库（Android 13+ 为系统照片选择器），选图后进入裁剪页
  - 单指拖动调整位置
  - 双指缩放
  - 框内就是最终背景，保存后不会再次拉伸
- **重新裁剪**：用上次的原图重新调整
- **移除背景**
- **背景遮罩**：0–80%，越大文字越清楚
- **网格线清晰度**：0–100%，0 为隐藏网格线

---

## 9. 桌面小组件

1. 「设置」→「桌面小组件」→「添加「今日课程」小组件」
2. 如果桌面不支持一键添加：长按桌面 → 窗口小工具 → 我的课表
3. 添加后可拉伸到 4×4；4×2 显示约 2 行课程

内容：

- 第几周 + 今天星期
- 今天课程（时间/课程名/教室），当前课高亮
- 最近 30 天内最近一场考试
- 点击任意位置打开 App

---

## 10. 更新

- 启动后会自动检查一次，发现新版本会弹窗询问，不会自动下载
- 也可以到「设置 → 更新 → 检查更新」手动检查
- 选择「立即更新」后，应用会从 GitHub 下载 APK、校验 SHA-256 和签名，再拉起系统安装器
- 应用内更新是覆盖安装，同签名版本会保留课表数据
- 首次更新需要允许「泥地课表」安装未知应用
- 如果系统仍然弹出安装确认，按提示确认即可
- 卸载重装或换手机会清除本地数据，需要重新从教务导入

---

## 11. 常见问题

**提取后没有课程？**

- 确认已进入「学生个人课表」并点过「查询」
- 确认表格已经显示出来
- 教务改版可能导致解析失效，需要在 `HtmlCourseParser` 中适配

**周次显示不对？**

- 检查「设置 → 开学第一周周一」
- 周次支持 `1-5,7-11`、`1-16周(单)`、`2-16周(双)`

**为什么两门课在同一格？**

- 它们的周次不重叠（例如 1-9 周与 10-17 周），这是正常排课

**为什么添加课程提示冲突？**

- 同一天、节次重叠且周次有交集；换一个节次或调整周次

**换手机/重装会丢数据吗？**

- 数据只在本机，卸载会删除
- 应用内覆盖更新不会丢数据
- 换手机或卸载重装后，需要重新从教务导入课表与考试

**小组件不刷新？**

- 华为等系统可能限制后台；打开一次 App 或重新添加小组件即可
- 小组件在 0 点、上下课、开机、时区变化时会自动刷新

**校外打不开教务？**

- 先连接学校 WebVPN，再在 App 内打开教务地址

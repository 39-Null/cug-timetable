# 更新记录

## 1.0.0 — 2026-10-30

首个成品版本。

### 课表

- 周一至周日 × 12 小节网格（南望山 10 小节）
- 左右滑动平滑切周，表头显示日期
- 仅系统当天所在周高亮当天
- 课程跨节显示，支持拖动换天/换节、拖下沿改时长
- 课程块显示课程名 / 教室 / 老师，缺失显示 `Null`
- 2–3 个汉字的老师名完整显示

### 导入

- 正方教务网页导入课程与考试，WebView 内登录，应用不接触密码
- PDF 导入（表格 / 文本兜底）
- 文本导入、手动添加
- 导入预览：追加 / 覆盖当前学期

### 学期

- 当前学期 + 历史课表
- 新建、重命名、删除、切换
- 历史课表拖拽排序
- 每个学期独立保存课程与考试
- 旧数据自动迁移到默认学期

### 考试与实验

- 考试导入、手动、粘贴
- 考试按日期/时间落到课表，红色「考试」块
- 实验类型（课程下属），琥珀色「实验」块，仅手动创建

### 校验

- 同天/同节次/周次有交集才判定冲突
- 保存、拖拽、导入均检查
- 小节时间格式与时长校验

### 主题

- 深色 / 浅色主题
- 本地背景图手动裁剪（拖动/缩放，按屏幕比例保存）
- 背景遮罩、网格线清晰度

### 桌面小组件

- 4×2 默认，可拉伸到 4×4
- 今日课程 + 最近 30 天内最近一场考试
- 点击打开 App
- 上下课、跨天、开机、时区变化自动刷新

### 其他

- 纯本地 SQLite，无账号、无广告、无统计
- 不落盘教务页面 HTML
- `allowBackup=false`

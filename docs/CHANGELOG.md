# 更新记录

## 1.1.7 — 2026-10-30

### 安全与稳定性

- WebView 只允许 http/https 导航，拦截 `file:`、`content:`、`intent:` 等 scheme
- 弹窗 WebView 取到 URL 后立即销毁，导入页退出时销毁主 WebView
- 新增 `network_security_config`：默认禁止明文，仅 `cug.edu.cn` 子域允许 HTTP
- 背景图裁剪坐标取整后做最终边界夹取，避免 `Bitmap.createBitmap` 越界崩溃
- 备份导入增加 16MB 总大小与 8MB 单图上限；背景图损坏不再让整次导入失败
- 更新包先写 `.part` 临时文件，校验完整后原子替换；取消标志改为 `AtomicBoolean`
- 打包脚本复制全部 `classes*.dex`，不再只复制 `classes.dex`
- 签名脚本要求显式 alias，密码通过环境变量传递，不再出现在命令行

### 数据完整性

- 课程节次必须满足 `1 ≤ 开始 ≤ 结束 ≤ 总小节数`
- 新建/编辑学期校验重名与开学日期；删除学期改为事务
- 设置页保存开学日期前先校验，DB 成功后再写 Prefs
- 课程/考试追加导入改为整批事务；课程追加前检查批次内冲突
- 考试导入校验小时/分钟范围；文本考试解析先 trim 再截取地点

### 体验与性能

- 学期列表课程数改为一次查询，去掉 N+1
- 背景图复制移到后台线程，避免大图阻塞 UI
- 小组件空状态使用明确文案，不再靠 `weekText` 前缀判断
- 移除 PDF 解析中含课表内容的调试日志

## 1.1.0 — 2026-10-30

### 内置更新

- 启动时自动检查 GitHub Releases，最多每 6 小时一次
- 设置页新增「更新」：显示当前版本、手动检查
- 应用内下载 APK，校验 SHA-256、包名、versionCode 和签名
- 使用 `PackageInstaller` 拉起系统安装器；Android 12+ 尝试免二次确认
- 只使用 GitHub 直链，不接第三方镜像
- 新增 `REQUEST_INSTALL_PACKAGES`、`UPDATE_PACKAGES_WITHOUT_USER_ACTION` 权限

### 数据备份

- 设置页新增「数据备份」：导出 / 导入 JSON
- 备份包含所有学期、课程、考试、设置、作息时间和背景图
- 导入前完整解析校验，事务替换；失败不影响原数据
- 导入前二次确认

### 移除

- 移除「按现在是第几周推算开学日」入口（新建学期、编辑学期、设置）

### 签名

- 正式版改用固定 release keystore，后续版本可直接覆盖升级
- 由于签名变更，旧版 GitHub 用户需要卸载重装一次；请先导出备份

## 1.0.0 — 2026-10-30

首个成品版本。

### 课表

- 周一至周日 × 12 小节网格（南望山 10 小节）
- 左右滑动平滑切周，表头显示日期
- 仅系统当天所在周高亮当天
- 课程跨节显示，支持拖动换天/换节、拖下沿改时长
- 课程块显示课程名 / 教室 / 老师，缺失显示 `Null`
- 2–3 个汉字的老师名完整显示

### 导入

- 正方教务网页导入课程与考试，WebView 内登录，应用不接触密码
- PDF 导入（表格 / 文本兜底）
- 文本导入、手动添加
- 导入预览：追加 / 覆盖当前学期

### 学期

- 当前学期 + 历史课表
- 新建、重命名、删除、切换
- 历史课表拖拽排序
- 每个学期独立保存课程与考试
- 旧数据自动迁移到默认学期

### 考试与实验

- 考试导入、手动、粘贴
- 考试按日期/时间落到课表，红色「考试」块
- 实验类型（课程下属），琥珀色「实验」块，仅手动创建

### 校验

- 同天/同节次/周次有交集才判定冲突
- 保存、拖拽、导入均检查
- 小节时间格式与时长校验

### 主题

- 深色 / 浅色主题
- 本地背景图手动裁剪（拖动/缩放，按屏幕比例保存）
- 背景遮罩、网格线清晰度

### 桌面小组件

- 4×2 默认，可拉伸到 4×4
- 今日课程 + 最近 30 天内最近一场考试
- 点击打开 App
- 上下课、跨天、开机、时区变化自动刷新

### 其他

- 纯本地 SQLite，无账号、无广告、无统计
- 不落盘教务页面 HTML
- `allowBackup=false`

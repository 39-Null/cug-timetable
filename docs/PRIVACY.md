# 隐私说明

## 1. 我们不收集什么

- 不收集账号、密码、学号、姓名
- 不上传课表、考试、成绩
- 不接入统计、崩溃上报、广告 SDK
- 不维护任何服务器

## 2. 登录如何完成

- 应用内打开学校教务/统一身份认证页面
- 账号密码只输入在学校页面里，由学校页面提交
- 应用不读取输入框、不拼接登录请求、不保存密码
- 不读取、不导出 Cookie

登录态由 WebView 自身的 Cookie 管理，行为与浏览器一致。

## 3. 数据存在哪里

| 数据 | 位置 | 其他应用可读 |
|---|---|---|
| 课程、考试、学期 | 应用私有 SQLite | 否 |
| 设置、主题 | 应用私有 SharedPreferences | 否 |
| 自定义背景图 | 应用私有 files 目录 | 否 |

- 不写入 `/sdcard` 公共目录
- 不生成任何教务页面 HTML 快照
- `allowBackup=false`，课程数据不会进入系统云备份
- 用户主动导出的 JSON 备份由用户选择保存位置；文件包含个人课表，请自行保管

## 4. 权限

| 权限 | 用途 |
|---|---|
| `INTERNET` | 打开学校教务页面（WebView）、检查 GitHub 更新 |
| `RECEIVE_BOOT_COMPLETED` | 开机后恢复桌面小组件的刷新闹钟 |
| `REQUEST_INSTALL_PACKAGES` | 应用内更新时拉起系统安装器 |
| `UPDATE_PACKAGES_WITHOUT_USER_ACTION` | Android 12+ 自更新时尽量免二次确认 |

不申请存储、定位、通讯录、相机、麦克风等权限。PDF/图片/备份通过系统文件选择器（SAF）授权访问单个文件。

## 5. 网络

- 学校教务页面：仅在你主动打开导入页时访问
- 更新检查：启动后最多每 6 小时请求一次 GitHub Releases API；只读取版本信息，不上传课表、账号或备份
- 更新下载：仅从 GitHub Releases 的 APK 直链下载
- 桌面小组件不联网，只读本机数据库
- 学校统一身份认证入口可能使用明文 HTTP（由学校配置决定），应用无法改变；请避免在不可信网络下登录

## 6. 删除数据

- 设置 →「清空数据」：删除当前学期的课程与考试
- 删除学期：删除该学期的课程与考试
- 卸载应用：删除全部本地数据
